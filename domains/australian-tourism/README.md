# Australian tourism domain pack

This is the initial example domain pack. It exists to compare open-web systems with curated Australian tourism retrieval systems, including ontology and non-ontology variants.

The pack itself does not depend on an ontology and does not define benchmark truth from a candidate index.

## Current scaffold

- 20 illustrative Australian locations;
- traveller, interest, and constraint value lists;
- three scenario templates;
- advisory source policy.

The location file is a small hand-curated demonstration dataset. Before a public benchmark release, replace or expand it with a versioned dataset and document its provenance and licence.
